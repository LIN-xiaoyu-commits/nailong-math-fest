# 数学建模社团 · 社团文化节 | 奶龙大学校园建设模拟赛

**在线玩：<https://lin-xiaoyu-commits.github.io/nailong-math-fest/>**

手机浏览器打开即玩，无需下载或注册。

![扫码玩](线上版二维码.png)

## 玩法

- 给你 **1000 万** 预算，当一学期校长，6 个校园场景里做选择：食堂、宿舍、图书馆、通勤、活动、期末预算。
- 每个方案都有成本、效果区间和翻车风险；结果封存到学期末一次性结算。
- 总分 ≥80 可以生成领奖凭证；低于 80 想重玩，先答对一道广告单选题（题库里 20 道数学建模相关题，答错会显示正确答案和错因，可改答案）。
- 名字只能靠掷骰子随机：形容词 + 且 + 形容词 + 的 + 水果 + 数字，例如「快乐且幽默的番茄123」。
- 线上排行榜（TinyWebDB）记录所有扫码玩家的成绩；本地/局域网模式也支持。

## 说明

- 本游戏仅供娱乐，与任何真实学校决策无关；奖品仅为社团文化节互动。
- 水果精灵贴图来自开源项目 [合成大奶娃 BigNaiWa](https://github.com/yhsome/BigNaiWa)，仅用于非商业社团活动展示。
- 数据/题库/数值都可在 `src/data/` 修改后用 `node build.mjs` 重新构建。
