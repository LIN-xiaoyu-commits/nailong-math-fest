# 奶龙大学 · 校园建设模拟赛

**在线玩：<https://lin-xiaoyu-commits.github.io/nailong-math-fest/>**

手机浏览器打开即玩，无需下载或注册。

![扫码玩](线上版二维码.png)

## 玩法

- 用 **1000 万** 预算经营一学期「奶龙大学」：从 16 个校园场景中随机抽 6 个，每关 4 个方案。
- 每个方案有成本、效果区间和风险；结果封存到学期末一次性结算。
- 总分 ≥80 生成领奖凭证，页面会醒目提醒「记得保存」；低于 80 想再来一局，要先答一道广告单选题。
- 广告题共 44 道，全部是数学建模题；每题每个选项都是一条数模小知识，点错会显示「点错了 + 错在哪里」，可以继续改答案。
- 每局随机打乱：6 个场景的抽取、每关选项顺序、广告题题目与选项顺序，不能背固定顺序。
- 名字只能掷骰子随机生成：形容词 + 且 + 形容词 + 的 + 水果 + 数字，例如「快乐且幽默的番茄123」。
- 结算页会用两小段解释：这些选择其实是一次简易的数学建模思考过程（目标、约束、方案比较、风险评估、复盘）。

## 说明

- 本游戏仅供娱乐，与任何真实学校决策无关；奖品仅为活动互动。
- 数据/题库/数值在 `src/data/` 修改后，用 `node build.mjs` 重新构建，并把新的 `index.html` 更新到仓库即可上线。
