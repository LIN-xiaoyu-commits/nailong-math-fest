# 数学建模社团 · 社团文化节 | 奶龙大学校园建设模拟赛

**在线玩：<https://lin-xiaoyu-commits.github.io/nailong-math-fest/>**

手机浏览器打开即玩，无需下载或注册。

![扫码玩](线上版二维码.png)

## 玩法

- 用 **1000 万** 预算经营一学期「奶龙大学」：6 个校园场景，每关 4 个方案。
- 每个方案有成本、效果区间和风险；结果封存到学期末一次性结算。
- 总分 ≥80 生成领奖凭证；低于 80 想再来一局，要先答对一道广告单选题（答错会显示答案和原因，可以改）。
- 名字只能靠掷骰子随机生成：形容词 + 且 + 形容词 + 的 + 水果 + 数字，例如「快乐且幽默的番茄123」。
- 广告题库 48 道，其中 20 道数学建模相关；线上排行榜记录所有扫码玩家的成绩。

## 说明

- 本游戏仅供娱乐，与任何真实学校决策无关；奖品仅为社团文化节互动。
- 数据/题库/数值在 `src/data/` 修改后，用 `node build.mjs` 重新构建，并把新的 `index.html` 更新到仓库即可上线。
